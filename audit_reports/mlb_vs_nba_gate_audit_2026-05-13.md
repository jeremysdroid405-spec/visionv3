| Capability | NBA | MLB | Parity? |

| Multi-book / DK-present penalty | ❌ not implemented either side | ❌ not implemented either side | parity (both gaps) |

### Critical structural deltas
1. **MLB Front Lines is currently in audit-mode** — `MLB_FRONT_LINES_GATES_DISABLED = True` since 2026-04-27. The hand-tuned `_mlb_fl_over(...)` per-family entries (HR 70-80 / CV 0.75-0.95) are layered in but the canonical production block (`_MLB_FRONT_LINES_FROZEN_AUDIT_2026_04_25`) is shelved. This explains the 75 qualified FLs at 5,639 supply — the per-family handhold is doing the gating.
2. **MLB Safe Haven** has no `vision_score_gate`, no L5 sub-gate, no override layer. It is hit-rate + edge + TP + per-family CV only. NBA's "elite vision rescue" (VS≥90 + CV≤0.35 → HR floor 75) and "pts dominance bypass" (HR≥90 + L20/line≥1.75) **do not exist for MLB**.
3. **MLB War Zone** ships `ceiling_gate{min: 35}` + `edge_gate{min: 30%}` and nothing else. No direction (it's stamped in `_mlb_thresholds`), no HR-expansion ladder, no vision_score gate. The 3,079 `war_zone_failed: gate_direction_fail` rejects + 292 `gate_ceiling_fail` are doing all the work.
4. **No UNDER path for MLB SH/WZ** — every MLB UNDER pick falls through `resolve_thresholds` to `_default` (the OVER config) because `_default_under` is only registered for FL.

## 3. Recommended rebuild — phased, additive

### Phase 1 (P0, ~1 day) — Stabilize the engine
- **OOM fix**: chunk `adapter.load_live_props` (currently `to_list(length=None)` on 5,639 MLB docs) + `recompute.py:386` companion-map cursor. Both behind `cursor.batch_size(200)` + async iteration.
- **Drop `replay_evaluations` + `replay_outcomes`** to free ~6.2 GB for Jan 2025 backtest ingestion.

### Phase 2 (P0, ~2 days) — MLB Front Lines un-freeze + parity
- Re-write `_MLB_FRONT_LINES` per-family with NBA-style structure: `direction_gate` (OVER + UNDER suffixes), `hit_rate_gate` (with `enforce_l5_subgate`), `cv_gate` (per-family cap map), `edge_gate`, `tp_gate`.
- Set `MLB_FRONT_LINES_GATES_DISABLED = False`.
- Add `_default_under` and `_default_over` blocks mirroring NBA `_NBA_FRONT_LINES_UNDER`.

### Phase 3 (P0, ~2 days) — MLB Safe Haven vision + override layer
- Add `vision_score_gate {"min": 80}` (calibrate after a 1-slate dry run — MLB has 4× the v2=0 share so we may need to start lower).
- Port the override structure: `__safe_haven_overrides__` with `elite_vision`, `pts_dominance` (or rename per-stat: `hits_dominance`, `total_bases_dominance`), `stat_family_cv_relax`.
- Add `_default_under` UNDER block (HR ≥ 65, gap ratio ≥ 0.15, CV cap with HR-relax).

### Phase 4 (P1, ~1 day) — MLB War Zone HR-expansion ladder + vision gate
- Add `vision_score_gate {"min": 60}` and `__war_zone_overrides__.hr_expansion_ladder` (Tier 2: HR ≥ 70 + edge > 0 → CV ≤ 1.15; Tier 3: HR ≥ 80 + edge ≥ 5 → CV ≤ 1.50).
- Add `_default_under` mirroring NBA.

### Phase 5 (P1) — Multi-book penalty (BOTH sports)
- Single-book NBA = 30.8%, single-book MLB = 18.9% — both deserve a `min_books` floor or DK-presence requirement in Safe Haven only (preserves FL/WZ supply).

### Phase 6 (P2) — Weak-model retrain
- HR, RBI, runs, doubles, SB, walks: more PA-level Statcast + matchup features.
